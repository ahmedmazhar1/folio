Folio Packaging API v1

Our own local packaging service. No Pacdora account or key is required.

Development service: bound to this computer only. This version has no authentication, supplier integration, order placement or production-grade packaging CAD.

Method / pathPurpose
GET /api/v1/healthService status
GET /api/v1/templatesOwn prototype templates, materials, limits
POST /api/v1/configurations/validateValidate and normalize dimensions to mm
POST /api/v1/estimatesIllustrative USD estimate
POST /api/v1/dielinesReview SVG, not production ready
POST /api/v1/sizing/recommendProduct dimensions plus adjustable clearance

Configuration request

Send JSON with Content-Type: application/json. Units: mm or in. Limits after conversion: L 100–400, W 80–300, H 30–200 mm. Materials: kraft, sbs, rigid. Finishes: matte, gloss, soft. Quantities: 100, 250, 500, 1000, 2500, 5000.

{
  "template_id": "mailer",
  "dimensions": {"L": 220, "W": 150, "H": 60},
  "unit": "mm",
  "material": "kraft",
  "finish": "matte",
  "quantity": 500
}

Template IDs: mailer, deep-gift, slim-flat. All three currently share the simplified prototype structure.

Sizing request

{
  "product": {"L": 210, "W": 140, "H": 50},
  "unit": "mm",
  "clearance_mm": 4
}

Returns a target internal size of 214 × 144 × 54 mm. Clearance is the total addition per dimension, not per side. The editor preview does not guarantee this usable internal space.

PakFactory sizing guidance provides a starting allowance; physical fit still needs validation.

Errors

422 invalid JSON or configuration, 413 body size limit, 415 wrong content type, 403 cross-origin request, 404 unknown route. Error responses include error and message. Maximum request body: 32 KiB.

Example

curl http://localhost:4173/api/v1/estimates \
  -H 'Content-Type: application/json' \
  -d '{"dimensions":{"L":220,"W":150,"H":60},"quantity":500}'

Folding engine

Open the standalone integration example. It loads a model through the API and drives its folds using the reusable browser renderer.

POST /api/v1/modelsPanel hierarchy, hinges, material thickness, fold phases, printable face identifiers. Accepts the configuration request above.
POST /api/v1/models/poseThe same configuration plus progress from 0 (closed) to 1 (flat). Returns panel angles in radians.
POST /api/v1/recommendationsProduct description, with optional product dimensions. Returns a recommended template, reasons and follow-up questions. Currently a rules engine, not AI.
// THREE is supplied by the host application.
const response = await fetch('/api/v1/models', {
  method: 'POST', headers: {'Content-Type':'application/json'},
  body: JSON.stringify({template_id:'mailer', dimensions:{L:220,W:150,H:60}})
});
const box = FolioFolding.mount(THREE, await response.json());
scene.add(box.group);
box.setProgress(0.5); // partially unfolded
box.dispose(); // release resources when removing the box

Additional template ID: tuck-carton (100 × 80 × 160 mm default). Renderer: /folding-engine.js. Panel schema 1.0; API v1. Geometry is for visual mockups, with no collision or manufacturing-fit guarantee.

Commercial API readiness

This is a local development API and reusable renderer. Paid access, customer accounts, API credentials, quotas, billing, hosted availability and a legal license agreement are not implemented. Do not expose this development HTTP server publicly.
